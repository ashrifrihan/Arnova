# Arnova.tech

A one-page premium technology startup website built with Next.js 16.4 and React 19.3.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Deploy

The project is ready for Vercel. Import the repository into Vercel and connect `arnova.tech` in Project Settings → Domains.

## Main files

- `app/page.tsx` — all one-page content and markup
- `app/globals.css` — full visual design, responsive layout, animations
- `app/layout.tsx` — SEO metadata

## Contact email

The CTA currently uses `hello@arnova.tech`. Change the `mailto:` link in `app/page.tsx` if needed.
